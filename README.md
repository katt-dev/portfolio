# katt — portfolio

Портфолио разработчика цифровых продуктов: игры, приложения, интерфейсы и серверные системы.

Сайт: https://katt-dev.github.io/portfolio/

## Разработка

Node.js 22.12+ или 24. `npm ci`, затем `npm run dev`.

`npm run build` проверяет TypeScript и собирает сайт в `dist/`. `npm run preview` запускает собранную версию.

## Содержимое

- `src/App.tsx` — страницы, кейсы, фильтры и форма подготовки сообщения в Telegram.
- `src/Mascot.tsx` — интерактивная чёрная субстанция, WebGL, сглаживание и поддержка уменьшенного движения.
- `src/style.css` — светло-серая тема и адаптивная вёрстка.
- `src/data/projects.json` — проекты и галереи.
- `src/data/site.json` — контакты и данные автора.
- `public/media/projects/` — изображения проектов и иконка Freeward VPN.

Шрифт Onest хранится локально, лицензия рядом: `src/assets/Onest-OFL.txt`. Счётчиков аналитики нет. Форма ничего не отправляет автоматически: посетитель сам отправляет подготовленный текст в Telegram.

## Публикация

GitHub Actions собирает и публикует `dist/` при push в `main`. В Settings → Pages источником должен быть GitHub Actions. Относительные пути поддерживают `/portfolio/`. Проекты открываются через `?project=<id>` без серверной маршрутизации.

## Интерфейс

Используется один вариант первого экрана: субстанция без демонстрации. Старый параметр `demo` больше не включает альтернативную версию.

`src/Navigation.tsx` — постоянная левая навигация на широком экране; на телефоне — закреплённая шапка с меню. Прокрутка не перестраивает панель и контент.

`src/Mascot.tsx` — плавная чёрная субстанция без реакции на курсор. Все значки используют один WebGL-рендер; кадр копируется только в видимые элементы. В скрытой вкладке отрисовка останавливается.

Обложка Colosseum воссоздана по `MainMenuView.cs` и `UiKit.cs`: фон — кадр из собственного ролика меню, шрифт Barlow Condensed из проекта (лицензия рядом). Это отмечено в кейсе; Unity для подготовки обложки не запускался.

Используется браузерная полоса прокрутки. Заливки наведения и обратные переходы заданы на базовом состоянии элементов; тематические анимации карточек не меняют их размеры. Субстанция остаётся только в маскоте и логотипе, без дополнительных масок в кнопках.

## Заливки

У чёрных кнопок используется мягкий белый блик. Темп постоянный — 0,7 секунды; начало совпадает с точкой входа курсора. При перемещении внутри кнопки точка не меняется, обратная анимация использует ту же точку. У фильтров проектов заливки при наведении нет; чёрная плашка меняет положение только при выборе фильтра. Прежние параметры `tempo` и `dark` больше не переключают оформление.

Субстанция имеет фиксированные центры и радиусы сгустков: меняется только общий масштаб в цикле 10 секунд. Дыхание выполняется композитором браузера; WebGL не перерисовывает неизменный силуэт каждый кадр. Начальное появление текста меняет лишь прозрачность после загрузки шрифта. В основной странице и кейсах прокрутка использует ограниченную по времени кривую с нулевой скоростью в конце. Для перехода обложки диалог открывается синхронно; в переходе участвует только выбранная обложка.

Выбор пункта навигации блокируется на время перехода к выбранному разделу, чтобы промежуточные разделы не подсвечивались. Точки трафика исчезают перед возвратом в начало. Список направления — отдельная светлая панель с автоматическим раскрытием вверх при нехватке места. Декоративной вертикальной линии в форме нет.

Субстанция медленно меняет локальный контур: три внешних сгустка отклоняются вокруг фиксированных центров по плавному шуму; ядро остаётся неподвижным. Общего масштабирования и вращения нет. Нажатие подтверждается короткой внутренней волной из точки клика; геометрия кнопки не меняется.

## Варианты иконок и система проекта

`?icons=custom` — отдельное движение для каждого вида иконки. `?icons=shared` — единый короткий отклик. Настройки заливок в обоих вариантах одинаковые.

Раздел «Один разработчик. Целая система» заменяет прежние вкладки услуг: интерфейс, логика, серверная часть и интеграции связаны с примерами из проектов. Превью в «Обо мне» и в схеме служат источником перелёта обложки.

`ProjectGallery.tsx` переключает декодированные изображения локальным кроссфейдом в постоянной рамке с `object-fit: contain`. Переход всего документа для кадров галереи не используется.

Движение субстанции адаптировано из `internal/bot/webapp/loader.js` Freeward VPN. Независимые плавные траектории замедлены, а смещения мягко ограничены внутри центрального сгустка — отдельные капли не отрываются.
